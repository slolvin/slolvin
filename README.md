## 📱 Featured Project: BRS (Bar Rating System) — Full-Stack MVP
*A comprehensive ecosystem (iOS App + Web Client + B2B CRM) for atomic item-based venue ratings, backed by a production-ready infrastructure.*

### 🏗️ Architecture & Infrastructure (Core Focus)
* **Containerization:** The entire ecosystem is fully isolated and orchestrated using **Docker Compose** (Backend, DB, Web Server).
* **Production-Ready Deployment:** Developed automated deployment scripts, configured an **Nginx/HTTPS** reverse proxy, and set up **automated SSL certificate renewals**.
* **Data Lifecycle:** Designed and implemented seamless database migration workflows for PostgreSQL.

### 💡 Product Features
* **Granular Analytics & Search:** Users can filter venues by the exact quality of a specific drink (e.g., *"Where is the best Apple Martini?"*). The search engine factors in real-time geolocation (distance) and opening hours.
* **Gamification & Engagement:** User dashboards featuring drinking logs, statistics, and venue check-ins via **QR codes**.
* **B2B CRM Panel:** A dedicated web application for bar managers providing item popularity analytics, menu management, and operation scheduling.
